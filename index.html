Projects

Replacing Managed Search Ingestion with DynamoDB Streams

Cost optimisation · In production

A media platform was paying around the clock for managed OpenSearch Ingestion pipelines. I compared seven options and built the replacement: DynamoDB Streams into a Lambda handler that maps each change to an index or delete with external versioning for conflict-safe writes, plus backfill, a dead-letter queue and disaster-recovery tooling. It ships as a Terraform module, so pipelines are added or removed declaratively.

Against an estate-wide baseline of about USD 13,975 a month, the new path costs about 98% less. A recovery test rebuilt 1,077,742 records in 172 seconds with no failures.

Stack: DynamoDB Streams, Lambda, OpenSearch, Python, Terraform

Organisation-Wide GuardDuty in 17 Regions

Security · In production since October 2026

GuardDuty was managed in a single region. I moved it to Terraform across all 17 regions with the Control Tower Audit account as delegated administrator, sent high and critical findings to Slack with threaded updates, and triaged and closed the outstanding high-severity findings.

A test with a real finding took about 3 minutes from detection to Slack, and it is repeatable from a sandbox. Seventeen design decisions are on record, including why alerts start at severity 7.0 rather than 9.0.

Stack: GuardDuty, Control Tower, EventBridge, Lambda, Terraform, Slack

Event Hub: Turning AWS Notices into Tracked Work

Architecture · Handed over before first deployment

AWS sends end-of-support, maintenance and security notices to every account, and across roughly 700 accounts they are easy to miss. I designed and largely built an event hub that reads AWS Health events and notice emails, normalises them into one validated event contract, classifies them with fixed rules and raises one Jira ticket per event, with a Slack alert when action is needed. AI writes the summary and never sets the priority.

24 recorded design decisions, 13 cross-field validation rules and a daily exposure report. Handed over to another engineer in October 2026.

Stack: Python, AWS Health, Lambda, Terraform, Jira, Slack

Root-Cause Investigation: Asset Ingest Race Condition

Reliability · 2026

I diagnosed a race condition in a cloud media asset management ingest pipeline: an encoder's temporary-file rename pattern made the storage gateway register a deletion and silently skip the finished asset. Log forensics across dozens of rotated gateway logs identified about 4 PB of duplicated media asset data from temp-file, atomic-save and partial-download patterns.

I defined scanner ignore patterns to suppress transient files, confirmed a reliable manual recovery step, and wrote a troubleshooting runbook and incident report so the wider team can repeat the diagnosis.

Stack: AWS, media asset management, cloud storage gateway, Linux, log analysis

Self-Service Account Vending on AFT

Platform design · Design stage, not yet built

I designed a self-service layer over Account Factory for Terraform: one web UI where teams request accounts into the right Organizations OU and track their lifecycle, owners manage access to their own accounts, and short-lived accounts destroy themselves when the requested period ends, with approved extensions. Finance Intelligence: Local-First Home Assistant Add-On

Personal project · Open source, ongoing

An open-source Home Assistant add-on for household finance analytics, built so banking data never leaves the user's own hardware: no outbound requests by default and an encrypted local volume. Statements come in from CSV, PDF and photos with local OCR, rules categorise them before any AI is involved, and optional AI categorisation can run entirely on a local LLM, with sensitive categories never sent. Multi-user with role-based access and TOTP, covered by pytest and Playwright suites, and released under Apache 2.0.
